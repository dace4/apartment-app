# US-10 — Apply immediately: user guide

**Apply immediately** sends your application to the owner right away. It does
**not** reserve the apartment: the apartment stays available until the owner
accepts an application.

## Apply immediately

1. Log in with a verified email address and the **Renter** role.
2. Open an **Available** apartment and select **Apply immediately**.
3. Fill in your full name, phone, move-in date and number of occupants (the
   message is optional). You can attach up to 5 documents from
   **Profile → My documents**.
4. Select **Apply immediately**. A message confirms that the application was
   submitted and that the apartment is not reserved.

You can only have one open application per apartment. If sending fails, select
the button again: the same application is retried and never stored twice.

## After applying

Your application appears in **Applications** with the status **Applied**. As
for any application, you can edit or withdraw it during 5 days while the owner
has not decided.

Applications that reserved an apartment before this change keep the status
**Reserved**.
