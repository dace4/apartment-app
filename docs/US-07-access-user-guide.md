# US-07: role access

Choose one or more roles during registration or edit them in Profile and press
Save roles. Features from all saved roles are combined. Verify your email first.
Existing accounts are prompted once to choose roles. On a loading error, use Retry
or Log out. If a profile save failed during signup, sign in and complete this prompt;
do not create a second account.

| Feature | Role |
| --- | --- |
| Browse, Profile, notifications | Any completed verified account |
| Favourites, comparison, saved searches, contact, applications, documents, signatures | Buyer or Renter |
| Immediate rental application | Renter |
| Mortgage, market trends | Buyer |
| Insurance | Renter |
| Contractors | Homeowner |
| Repair & maintenance (app maintenance windows) | Admin |

A selected role never proves property ownership. Ask the project team to assign the
correct property to your Firebase account. The Admin role is also given by the project
team; an admin can open every page (see admin-maintenance-user-guide.md).

Saving a different set of roles returns you to the homepage and clears the previous
screens and in-memory selections. Your stored records remain in your account and
become accessible again when you select the relevant role. An unauthorized direct
link returns to the homepage.
