# US-12 — Owner and manager inbox: user guide

Owners (Homeowner) and property managers can read the questions renters and
buyers send about their apartments with **Contact advertiser**.

1. Open **Profile → Inbox**. The entry only appears with the Homeowner or
   Property Manager role.
2. The **Applications** tab lists the applications for your apartments (see the
   US-16 guide to review them).
3. The **Messages** tab lists the messages about the apartments you own or are
   assigned to, newest first, with the apartment and the sender's email.
4. Select a message to read its subject, sender, date and full text. Answer the
   sender by email.

Use **Refresh** at the top to load new applications and messages.
