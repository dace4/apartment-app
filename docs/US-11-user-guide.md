# US-11 — My Signature and document binding

## Create or replace your signature

1. Log in with a verified email address and open **Profile → My Signature**.
2. Draw in the box with your finger, stylus, or mouse. A blank drawing or a dot
   cannot be saved. Use **Clear drawing** to start again.
3. Select **Save signature** and wait for **Signature saved**.
4. Reopen the screen whenever you want to change it. Clear the old drawing, draw
   a replacement, and select **Replace signature**. This keeps the same signature ID.

Clearing the drawing only changes your draft. Your saved signature is replaced
only after a successful save. Connection errors leave the draft available to retry.

## Bind a signature to a document

1. Open **Profile → My documents**. Upload JPEG/PDF files using the US-15 workflow,
   or select a file you already uploaded.
2. Review the file preview and select **Bind signature**.
3. Read the confirmation naming the file, then select **Confirm and sign**.
   **Cancel** makes no change.
4. Once confirmed by the server, the file shows **Signed** and its binding time.
   The binding button disappears. Reopening the file retains this state.

Without a saved signature the button is disabled. Use **Set up My Signature
before signing**, save your drawing, then return to the file. The screen reloads
the saved signature automatically. Use the refresh button after a connection error.

Binding records your signature ID and the signing time. It does **not** insert a
signature image into the JPEG or PDF. Replacing your saved drawing later keeps
existing files Signed under that same ID; there is no older drawing history.
The app does not authenticate handwriting or issue a digital signing certificate.

A failed confirmation never displays a successful signature. Retry after restoring
connectivity; if the binding already saved, retry confirms the existing state
without changing its original time. Leaving the screen does not cancel an operation
already submitted. Signed files cannot be removed or overwritten.

Documents may be attached to applications with or without signing. See the
[US-15 user guide](US-15-user-guide.md) for file limits, previews, and attachments.
