# Services

The Services tab shows tools according to your account roles.
Existing tools include mortgage estimates, repair and maintenance, and insurance.

## Renovation contractors

Homeowners can browse a Firebase-backed directory of six fictional contractors and filter by city.
See [the contractor user guide](../renovation-contractors-user-guide.md).

## Market trends

The separate `feature/market-trends` branch adds a Firebase-backed sample price history for buyers.
After that branch is integrated, see `docs/market-trends-user-guide.md` for usage.

Both new catalogues require approved Firebase rules deployment and demo-data seeding before they contain data.
