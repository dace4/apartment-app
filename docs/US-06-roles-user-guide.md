# US-06: choosing roles

During registration, select one or more roles: Buyer, Renter, Homeowner, Property Manager.
Open the confirmation email and verify it before using the app.
Existing accounts choose roles once after verification. Save roles to continue.
In Profile, change the checkboxes and press Save roles. At least one role is required.
If saving fails, retry. If account creation succeeded but verification email or profile
saving failed, use the signed-in verification screen (Resend email) and role selection;
do not register a second account. Sign in if the app was closed.
A profile loading failure shows Retry and Log out. Selecting Homeowner or Property Manager
never assigns a property.
