# US-16 — Track and review applications: user guide

## As an applicant (Buyer or Renter)

Open **Applications** to see your applications and their status:

| Status | Meaning |
| --- | --- |
| **Applied** | You sent the application. |
| **Received** | The owner or manager has received it. |
| **In review** | The owner or manager is reviewing it. |
| **Accepted** / **Rejected** | The decision. |
| **Withdrawn** | You withdrew it. |

You receive a notification (**Profile → Notifications**, type "Application
status") each time the status changes. You can still edit or withdraw an
application during 5 days after sending it, while it is Applied, Received or In
review.
If you withdraw an application that is In review, the apartment becomes
Available again for others.

## As an owner or assigned admin (Homeowner or Admin)

1. Open **Profile → Inbox**. It lists the applications for the apartments you
   own (Homeowner) or are assigned to (Admin), newest first.
   Immediate applications are marked **Immediate**.
2. Select an application to see the applicant's details.
3. Move it to the next step: **Mark as received**, then **Start review**, then
   **Accept** or **Reject**. Steps cannot be skipped, and a decided or
   withdrawn application cannot be changed.

The apartment's availability follows your review:

| You | The apartment becomes | Other applications |
| --- | --- | --- |
| **Start review** | **Reserved**: nobody else can apply | Wait. Only one application per apartment can be In review: accept or reject it before starting another. |
| **Accept** | **Unavailable** | The other open applications are rejected automatically and their applicants are notified. |
| **Reject** (the one in review) | **Available** again | One of them can now be reviewed. |

If an automatic rejection fails, a message says so: open that application from
the inbox and reject it.
